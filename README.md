# Ghost Net Rescue — นักล่าอวนผี

เกมแนว Underwater Rescue Arcade: รับบทนักดำน้ำล่าอวนผี ตัดอวนช่วยสัตว์ทะเลให้ได้มากที่สุดใน 90 วินาที
แรงบันดาลใจจากโปสเตอร์ "Ghost Fishing Net" ของ Chula Zero Waste

## วิธีเล่น
- **แตะ/คลิกที่สัตว์ที่ติดอวนครั้งเดียว** ปลดอวนได้ทันที: ปลา 10 / เต่า 25 / โลมา 40 / พะยูนทอง 80 + 5 วินาที — ถ้าเล่นด้วยคีย์บอร์ด ว่ายเข้าใกล้แล้วจะตัดให้อัตโนมัติ
- **พุ่ง** (คลิกที่ว่าง · Space · แตะที่ว่างสองครั้ง · ปุ่มพุ่ง): ฉีกอวนผีขาดได้ (+15) และใช้หลุดจากอวนทันที คูลดาวน์ 1.8 วินาที
- ช่วยต่อเนื่องภายใน 4 วินาทีได้คอมโบ คูณคะแนนสูงสุด x5
- คอมโบครบ 5 เข้าโหมด **FEVER** 7 วินาที: คะแนน x2 อวนผีหนี และชนแล้วแตก
- ช่วยไม่ทันวงแหวนชีวิตหมด อวนจะกลายเป็นอวนผีที่ไล่ตามผู้เล่น (วงจรอวนผี)
- วินาทีที่ 40 **ราชาอวนผี** ปรากฏตัว พ่นอวนผีลูกน้อง พุ่งชน 3 ครั้งเพื่อทำลาย ได้ +300 คะแนน +10 วินาที และปล่อยสัตว์ 5 ตัว
- ฟอง O₂ = +5 วินาที, ฟองมีดยักษ์ = 8 วินาที แตะทีเดียวช่วยตัวที่อยู่ใกล้ ๆ ได้ทั้งกลุ่ม

P = พัก · M = เสียง/เพลง

## เอาขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub เช่น `ghost-net-rescue`
2. อัปโหลด `index.html` และ `README.md` (Add file → Upload files → Commit)
3. ไปที่ Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
4. รอประมาณ 1 นาที เกมจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/ghost-net-rescue/`

เกมเป็นไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม (ใช้ HTML5 Canvas + JavaScript ล้วน)

## เก็บข้อมูลผู้เล่นลง Google Sheets (Apps Script)
1. สร้าง Google Sheet ใหม่ → ส่วนขยาย → Apps Script → วางโค้ดจาก `apps-script/Code.gs` → บันทึก
2. Deploy → New deployment → ประเภท Web app → Execute as: **Me** → Who has access: **Anyone** → Deploy
3. คัดลอกลิงก์ที่ลงท้ายด้วย `/exec`
4. เปิด `index.html` ค้นหา `APPS_SCRIPT_URL` แล้ววางลิงก์ไว้ในเครื่องหมายคำพูด เช่น
   `const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/xxxx/exec';`

ข้อมูลที่บันทึก (1 แถวต่อ 1 รอบเล่น): เวลาเริ่ม, Play ID, ชื่อ, แผนก, ครั้งที่, นักดำน้ำ, สถานะ, คะแนน, ช่วยได้, สูญเสีย, ฉีกอวนผี, เวลาจบ, รหัสอุปกรณ์

เมื่อใส่ลิงก์แล้ว ระบบจำกัด 3 ครั้งจะเช็กจากชีตด้วย จึงนับรวมทุกเครื่อง
ถ้าแก้โค้ด Apps Script ภายหลัง ต้อง Deploy → Manage deployments → แก้ไข → New version

## Ranking Top 10
ปุ่ม "Ranking Top 10" อยู่ใต้ปุ่มเริ่มเกม และในหน้าสรุปผล
- ใส่ลิงก์ Apps Script แล้ว: แสดงคะแนนดีที่สุดของแต่ละคน (ชื่อ + แผนก) จากทุกเครื่อง ดึงจากชีต
- ยังไม่ใส่ลิงก์: แสดงเฉพาะผู้เล่นในเครื่องนั้น
- คะแนนเท่ากัน คนที่ทำได้ก่อนอยู่อันดับสูงกว่า

ถ้าเคย Deploy Apps Script ไปแล้ว ต้องวางโค้ด `Code.gs` ใหม่ แล้ว Deploy → Manage deployments → แก้ไข → New version
